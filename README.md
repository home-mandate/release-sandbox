# release-sandbox

A throwaway repository to try the release workflow of the `home-mandate` organization with
real tags: release branches, release candidates, the release gate, and a version on the commit
of a release candidate that passed
([RELEASING.md](https://github.com/home-mandate/.github/blob/main/RELEASING.md)).

Nothing here is a product, and nothing here is meant to be used. The repository is archived
when the trial is done.
